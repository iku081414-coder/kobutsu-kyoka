# 古物商許可ナビ（無料・登録不要）

古物商の許可申請に必要な書類を、質問に答えるだけで自分専用のチェックリストにする静的Webアプリ。SaaS100本連載の #003（#002 古物台帳の「入口」）。

- サーバーなし。答えとチェックはブラウザの localStorage だけ。外部への通信なし（CSPで遮断）
- 書類の作成・申請代行はしない（行政書士法に配慮）。チェックリストと説明まで
- 情報源：警視庁・神奈川県警・大阪府警・愛知県警の公式ページ（`content/research/kobutsu-kyoka-facts.md`）

手元で動かす：`python3 -m http.server 3300` → http://localhost:3300
公開：GitHub Pages（main の / をそのまま）。ファイルを変えたら `sw.js` の `CACHE` を上げる。
運営コスト：0円
